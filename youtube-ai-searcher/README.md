# 🎬 AI 유튜브 검색기 (AI YouTube Searcher & Navigator)

유튜브 영상 URL을 입력하면 영상을 즉시 브라우저에서 재생하고, **Gemini 3.5 Transcribe**로 오디오와 초 단위 타임스탬프를 추출하며, **Gemini 3.8 Flash**를 통해 영상 내용을 자연어로 검색·질의응답하고 원하는 장면으로 즉시 점프(Seek & Play)할 수 있는 지능형 영상 내비게이터 웹 서비스입니다.

---

## 🌟 주요 기능

1. **유튜브 다크 테마 UI 레이아웃**
   - 상단 중앙 둥근 검색창에 유튜브 링크를 입력하고 검색 버튼 클릭.
   - 불필요한 마이크, 만들기, 알림 버튼을 제거하여 영상과 AI 대화에 집중할 수 있는 깔끔한 환경 제공.
2. **YouTube IFrame API 연동 및 음향 크기 조절**
   - 검색 즉시 영상이 임베드되어 고화질로 재생.
   - **커스텀 음향 크기(볼륨 0~100%) 조절 슬라이더**, 음소거 토글, 5초 앞/뒤 탐색 버튼 지원.
3. **Gemini 3.5 Transcribe 기반 정밀 타임스탬프 추출**
   - `gemini-3.5-transcribe` 모델의 `word_timestamp` 기능을 활용하여 문장/단어별 정확한 발화 초(Seconds)와 텍스트를 추출.
   - 우측 '전체 자막 타임스탬프' 탭에서 시간대별 대사를 한눈에 확인 가능.
4. **Gemini 3.8 Flash 기반 영상 내용 검색 & 타임스탬프 이동 (Seek & Play)**
   - 궁금한 장면이나 대사를 질문하면 `gemini-3.8-flash` 모델이 영상 내용을 분석하여 답변.
   - 답변 내 타임스탬프(예: `[00:04 ▶]`)를 클릭하면 **좌측 유튜브 영상이 해당 시간으로 즉시 이동(`seekTo`)하고 자동 재생(`playVideo`)**.
5. **범용 핵심 색인/챕터(Key Entities & Chapters) 색인 탐색기**
   - 포켓몬, 건담, 요리, 테크 리뷰, 강의 등 어떤 장르의 영상을 입력해도 **핵심 개체/인물/조리단계/소주제 챕터 목록**을 자동 추출.
   - 우측 3번째 탭 **[📌 핵심 색인 목록]**에서 타임 배지 + 제목 + 1줄 설명 카드로 시각화 (클릭 시 원클릭 Seek & Play).
   - 좌측 플레이어 하단 **빠른 이동 태그 칩스(`[#00:04 인트로]` 등)**를 통한 직관적 탐색 지원.
6. **CSV 기반 트랜스크립트 & 색인 자동 영구 저장 & 스마트 캐싱 (Speed 0.1s)**
   - 동일한 유튜브 URL이 들어올 경우 매번 Gemini API를 호출하지 않고, **`transcripts_cache.csv` 파일에 영구 보관된 자막 및 핵심 색인 데이터를 즉시(0.1초) 로딩**.
   - 신규 링크일 경우에만 AI 분석 후 CSV에 자동 기록되어 API 호출 비용과 대기 시간을 획기적으로 절약.

## 📂 폴더 구조

```text
youtube-ai-searcher/
├── app.py                 # FastAPI 백엔드 (yt-dlp, Gemini 3.5 Transcribe, Gemini 3.8 Flash 연동)
├── static/
│   └── index.html         # YouTube 다크테마 UI + IFrame 플레이어 + 볼륨 조절 + AI 챗봇
├── downloads/             # 임시 오디오 보관소
├── requirements.txt       # 의존성 패키지 목록
└── README.md              # 프로젝트 안내서
```

## 🚀 실행 방법

### 1. 전용 폴더로 이동
```bash
cd youtube-ai-searcher
```

### 2. 패키지 확인 (이미 설치되어 있다면 생략 가능)
```bash
pip install -r requirements.txt
```

### 3. 웹 서버 실행 (포트 8001)
```bash
python app.py
```

### 4. 웹 브라우저 접속
👉 **[http://127.0.0.1:8001](http://127.0.0.1:8001)**
